# Основа сайта Веры Дуденковой

Состояние на 29 сентября 2026 года: первая рабочая версия, пока Вера готовит биографию и условия тренировок.

## Задача

Потенциальный ученик должен быстро понять, что Вера — тренер по большому теннису в Москве, увидеть её и перейти к разговору о занятиях. Конкретные группы учеников, формат и позиционирование пока не подтверждены. Поэтому мы не строим предложение на предположениях о детях, новичках, соревнованиях или индивидуальных занятиях.

## Композиция

Визуальное направление — спортивная редакционная подача с Wimbledon как главным референсом. По прямому выбору Антона ключевой кейс — [Further / Wimbledon](https://www.further.group/work/wimbledon): строгий порядок и живая энергия игры. Тёплый белый, зелёный корта и фиолетовый акцент; Commissioner для имени и текста, Bona Nova Italic для личных фраз. Крупный реальный портрет, двойная тонкая линия и графика полос/дуг связывают теннисное настоящее Веры с её прошлым в спринте. Системная тёмная тема использует ту же иерархию.

Содержание: знакомство с Верой → короткая личная история о спринте и любви к Уимблдону → фотография теннисного инвентаря и контакт. Подробная биография, форматы, адреса, цены и FAQ появятся после ответов Веры, если они помогут посетителю принять решение. Исследованные кейсы и принятые решения — в [DESIGN.md](DESIGN.md).

## Техническая основа

Статический HTML/CSS, локальные изображения, нативные ссылки. Без фреймворка, сборщика клиентского кода, сторонних виджетов, аналитики и базы данных. Node.js нужен только для проверки, локального сервера и копирования в `dist/`. GitHub Actions запускает проверки; отдельный workflow готовит публикацию GitHub Pages.

Путь проекта `/vera/` поддержан относительными ссылками. Сборка публикует только `site/`; рабочие документы и исходные архивы не входят в артефакт сайта. Репозиторий публичный.

## Когда считать сайт готовым к запуску

Вера подтверждает основные тексты, актуальный способ связи и фотографии; получены условия занятий; выполнена проверка мобильной/большой композиции, клавиатуры, контраста и ссылок; проверен публичный URL. После этого снимаем `noindex` и уточняем метаданные. До этого страница остаётся рабочей основой.
