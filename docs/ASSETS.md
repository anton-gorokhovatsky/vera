# Материалы сайта

Обновлено 30.09.2026. Материалы Веры взяты из Instagram по прямому запросу Антона. Страница загружает локальные файлы; подписанные CDN-адреса и личные данные аккаунта не публикуются.

## Галерея

Все 11 изображений и 12 видео из [каталога Instagram](INSTAGRAM.md) включены в `site/assets/gallery/`. Имя файла сохранено, JPEG заменён на WebP. Источник каждого файла — соответствующая строка каталога; он также доступен из просмотра на сайте. Исходники сохранены в игнорируемом `.local/instagram-tennis/library/`.

Видео: H.264, до 720 px по ширине, 30 fps, CRF 28, yuv420p, faststart; при наличии звука — AAC 96k. Полный монтаж, длительность и звук сохранены. Единственное исходное видео без звука — `tennis-28.mp4`. Разница длительности после перекодирования всех 12 роликов меньше 0,08 с. Уменьшение частоты кадров не является ускорением видео.

Изображения: WebP quality 88, максимум 1080×1920. Превью в `thumbs/` — до 480 px по ширине. Постеры видео — WebP. Превью утреннего влога выделяет горизонтальное окно кадра; полная версия сохраняет исходные поля. Генерации и ретуши людей нет.

`rally-preview.mp4` — немой шестисекундный фрагмент `tennis-25.mp4`, отметки 5–11 с. Используется как фоновый тизер; нажатие открывает полный 30-секундный ролик со звуком. Превью и постеры не являются дополнительными материалами каталога.

Каталог с превью занимает около 24,1 МиБ на сервере, но не скачивается целиком при открытии страницы. Изображения ленивые; полные видео загружаются в просмотре. Два коротких фоновых видео постеров запускаются при видимости, если разрешено движение.

## Портрет и трава

- `vera-portrait.jpg`: [публикация DbLxLAtjErr](https://www.instagram.com/vera_dudenkova/p/DbLxLAtjErr/), 1080×1440, 144 656 байт. Портрет для биографии, не кадр теннисной тренировки.
- `grass-court.mp4`: адаптация макровидео травы из первого экрана [Further / Wimbledon](https://www.further.group/work/wimbledon), по прямому предложению Антона использовать это движение. Исходный ролик 1920×1080, 6,7 с содержит эмблему турнира в центре. Взята правая область 800×1080 с x=1120, целиком за пределами эмблемы. Веб-копия 720×972, 25 fps, H.264 CRF 29, без звука, 442 321 байт. Это материал Further, не авторская съёмка проекта Веры. Отдельная лицензия на ролик не проверялась.
- `grass-court.webp`: кадр того же фрагмента на отметке 2 с, 720×972, 22 324 байта. Статичный фон и фактура зелёного постера.

Прежние дубли подачи, JPEG корта и два файла Rise удалены из `site/`: они больше не используются. Источники остаются в локальном архиве и истории Git.
