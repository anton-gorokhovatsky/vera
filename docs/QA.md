# Проверка первой версии

Дата: 29 сентября 2026 года. Это рабочая основа сайта; окончательное предложение и выбор материалов ещё дополняются вместе с Верой.

## Локальная проверка

- `npm run build` включает статические проверки и сборку только каталога `site/`.
- Проверены локальные ресурсы, якоря, метаданные, один h1 на страницу, язык документа, описания и размеры изображений, отсутствие сторонних скриптов и форм. Общий размер сайта — около 201 КБ.
- В браузере осмотрены первый экран, контактный блок и подвал. Проверены ширины 320, 390, 768 и 1280 CSS px; горизонтального переполнения в проверенных состояниях нет.
- Тёмная тема проверена при системной тёмной настройке. Для светлой темы использована временная локальная копия с отключённым тёмным медиазапросом; она не входит в сборку и Git. Это проверка светлых токенов и композиции, не тест переключения настройки ОС.
- Проверено увеличение базового размера текста до 200% при ширине 320 px в отдельной локальной копии: контент доступен без горизонтальной прокрутки. Это не проверка всех сочетаний браузерного zoom и системного размера шрифта.
- Переход к основному содержимому перемещает фокус в `main`. Ссылка «О тренировках» с клавиатуры открывает контактный блок. При переходе клавишей Tab виден контур фокуса толщиной 3 px. Все ссылки имеют высоту не менее 44 px.
- Обе фотографии загружаются. В проверенной странице нет сообщений об ошибках и предупреждений в консоли.
- Сценарий работает на обычных ссылках без JavaScript. Анимации и плавная прокрутка не используются, поэтому отдельного движущегося состояния для reduced motion нет.

## Границы проверки

Точечное обновление 29.09.2026: тексты переведены на первое лицо Веры, включая подпись, описание страницы и 404. `npm run build` и `git diff --check` прошли; контактный блок осмотрен на ширине 390 px, переполнения нет. Публичный результат проверяется после завершения Pages; графика и компоновка этой правкой не меняются.

Следующая точечная правка: знак теннисного мяча и favicon используют две непересекающиеся дуги шва. Знак осмотрен в шапке при штатном размере 27 px; сборка и проверка diff прошли. У favicon обновлён параметр версии, чтобы браузер загрузил исправленный рисунок.

Обновление кнопок по замечанию Антона и статье Uprock: подпись главного действия — «Обсудить тренировку», округлая форма, отдельные SVG-стрелки, цветовые состояния hover/active и существующий видимый focus. В браузере проверены светлая композиция при 1280 и 390 px, тёмный контактный блок при 320 px, активация якоря клавишей Enter, фактический hover без подчёркивания и видимый фокус. В проверенных мобильных состояниях ширина кнопок равна ширине текстового блока, высота — 56 px, переполнения нет. Светлая тема проверялась в локальной копии, как описано выше. Active определён в CSS; удержание указателя отдельным кадром не фиксировалось.

Использован браузер Codex с изменением размеров окна. Физические iPhone/Android, ручной скринридер, полный аудит WCAG и показатели полевых Core Web Vitals не проверялись. Успешная сборка не заменяет визуальное согласование с Антоном и Верой.

Обе страницы сохраняют `noindex, nofollow`, пока контент готовится. Это рекомендация поисковикам, а не ограничение доступа по публичной ссылке.

## Шрифты и направление Wimbledon — 29.09.2026

- Локально подключены Commissioner Regular/Medium и Bona Nova Italic с лицензиями OFL. В браузере осмотрен русский набор имени, заголовков, основного текста, кнопок и подписей. Ошибок загрузки шрифтов в консоли нет.
- Проверена композиция от первого экрана до подвала: тёмная тема на 390, 768 и 1280 px; светлая — на 320, 1280 и 1440 px. Светлая тема проверена отдельной локальной копией с отключённым тёмным медиазапросом, без изменения настроек ОС. После увеличения масштаба имени широкий первый экран повторно осмотрен на 1440 px.
- На 320 px при базовом размере текста 200% исправлены горизонтальные отступы кнопок и переполнение курсивных фраз. Повторный DOM-контроль показал нулевое переполнение страницы и проверенных элементов; текст и обе кнопки доступны. Крупные заголовки на такой ширине переносятся внутри длинных слов. Это проверка reflow локальной копии, не всех сочетаний браузерного zoom и системного шрифта.
- Skip-link перемещает фокус в `main`; Enter на главном действии открывает `#contact`; клавиатурный фокус у ссылки Instagram имеет видимый контур 3 px. Зоны ссылок — от 44 px, кнопки в обычном размере — 56 px. Контакт ведёт в профиль `vera_dudenkova`.
- У фотографий сохранены источники и размеры. Rise подключён статичным локальным SVG; анимаций и runtime-зависимостей нет. Новые файлы и лицензии включены в бюджет сайта — около 504 КБ суммарно.
- Рассчитанный контраст новых основных текстовых сочетаний — от 5.12:1 (фиолетовый текст на светлой сиреневой поверхности). Контраст кнопки в светлой теме — 10.48:1, hover — 7.32:1. Это проверка заданных цветов, не полный аудит WCAG.
- `npm run build` и `git diff --check` выполняются перед выпуском. Публикуется только `site/`; временные копии и материалы проверки исключены из Git и сборки. Публичная проверка записывается после завершения Pages.

Границы: браузер Codex и изменение viewport; физические устройства и ручной скринридер не проверялись. Согласование визуального характера с Антоном и Верой остаётся человеческой оценкой.
