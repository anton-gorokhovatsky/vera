# Проверка первой версии

Дата: 29 сентября 2026 года. Это рабочая основа сайта; окончательное предложение и выбор материалов ещё дополняются вместе с Верой.

## Локальная проверка

- `npm run build` включает статические проверки и сборку только каталога `site/`.
- Проверены локальные ресурсы, якоря, метаданные, один h1 на страницу, язык документа, описания и размеры изображений, отсутствие сторонних скриптов и форм. Общий размер сайта — около 201 КБ.
- В браузере осмотрены первый экран, контактный блок и подвал. Проверены ширины 320, 390, 768 и 1280 CSS px; горизонтального переполнения в проверенных состояниях нет.
- Тёмная тема проверена при системной тёмной настройке. Для светлой темы использована временная локальная копия с отключённым тёмным медиазапросом; она не входит в сборку и Git. Это проверка светлых токенов и композиции, не тест переключения настройки ОС.
- Проверено увеличение базового размера текста до 200% при ширине 320 px в отдельной локальной копии: контент доступен без горизонтальной прокрутки. Это не проверка всех сочетаний браузерного zoom и системного размера шрифта.
- Переход к основному содержимому перемещает фокус в `main`. Ссылка «О тренировках» с клавиатуры открывает контактный блок. При переходе клавишей Tab виден контур фокуса толщиной 3 px. Все ссылки имеют высоту не менее 44 px.
- Обе фотографии загружаются. В проверенной странице нет сообщений об ошибках и предупреждений в консоли.
- Сценарий работает на обычных ссылках без JavaScript. Анимации и плавная прокрутка не используются, поэтому отдельного движущегося состояния для reduced motion нет.

## Проверка публикации

После отправки в `main` необходимо дождаться успешных `Quality` и `Pages` для опубликованного коммита, открыть публичную страницу с параметром версии, сверить HTML/CSS/изображения с локальной сборкой и проверить вложенный URL страницы 404. Результат первичной публикации и рабочая ссылка сообщаются в отчёте о выпуске.

## Границы проверки

Использован браузер Codex с изменением размеров окна. Физические iPhone/Android, ручной скринридер, полный аудит WCAG и показатели полевых Core Web Vitals не проверялись. Успешная сборка не заменяет визуальное согласование с Антоном и Верой.

Обе страницы сохраняют `noindex, nofollow`, пока контент готовится. Это рекомендация поисковикам, а не ограничение доступа по публичной ссылке.
