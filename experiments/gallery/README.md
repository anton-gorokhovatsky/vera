# Три локальные версии «На корте»

Запрос Антона от 09.10.2026: выбрать одно место сайта, собрать 2–3 дерзких экспериментальных переделки и посмотреть вместе. Выбрана галерея: она содержит реальные теннисные материалы и позволяет сравнить композицию, не придумывая содержание.

- **А · Корт.** Кортовые поля задают распределение видео и фотографии; зелёное центральное поле, асимметричные боковые зоны, жёлтое приглашение.
- **Б · Фотозин.** Светлый редакционный разворот, крупная типографика, смещение и различный масштаб кадров.
- **В · Киноэкран.** Большой ролик, подпись после изображения, короткая программа и крупное приглашение.

## Запуск

```sh
node experiments/gallery/build.mjs
PORT=4188 node scripts/serve.mjs artifacts/vera-gallery-lab
```

Сравнение: <http://127.0.0.1:4188/vera/lab/>. Полные страницы: `court/`, `zine/`, `cinema/`, в каждом есть `zh/`. Текущая версия доступна в корне `/vera/`.

Сборщик копирует текущую основу из `site/` в игнорируемую папку `artifacts/vera-gallery-lab/` и заменяет только галерею. Исходный сайт и производственная сборка не импортируют файлы эксперимента. У каждой версии те же 23 уникальных материала и существующий нативный проигрыватель. Снимки для страницы сравнения находятся в `artifacts/vera-gallery-lab/lab/previews/`.

`large.html` — проверочная копия с корневым текстом 200%; `static.html` — копия без скриптов. `light.html` / `dark.html` принудительно включают соответствующую ветку исходного CSS. `reduced.html` включает статичный режим в CSS и через `matchMedia`, чтобы проверить поведение существующего движения. Это локальные условия проверки, не системная смена настроек браузера. Перевод использует существующий словарь проекта; новых фактов о Вере нет.

Применимые правила: NNG-02–04, 09–16, 17–27, 32, 35–36. 9 октября Антон прямо выбрал «Фотозин»: его доработанная версия встроена в `site/index.html` и `site/zine.css`. «Корт» и «Киноэкран» сохраняются как локальные альтернативы; файлы лаборатории не входят в `dist/`. Повторная сборка лаборатории берёт текущую основную страницу, поэтому не является снимком прежнего релиза. Результаты осмотра и ограничения — в `docs/QA.md`.
