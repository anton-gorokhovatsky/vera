# Вера Дуденкова · Большой теннис

Рабочая основа сайта тренера по большому теннису. Подтверждены имя, профессия, Москва, спортивное прошлое, курс ФТР по программе ITF и запись через директ. Собран локальный архив теннисных материалов из Instagram. Полное предложение собирается вместе с Верой.

## Запуск

Нужен Node.js 22 или новее. Установки пакетов нет.

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173/vera/`. Для другого порта: `PORT=4174 npm run dev`.

```sh
npm run check
npm run build
npm run preview
```

`check` проверяет базовые инварианты HTML, локальные ссылки/ресурсы, размеры и описания изображений, режим индексации и вес. Он не заменяет HTML-валидатор, аудит доступности и осмотр страницы в браузере. `build` сначала генерирует китайскую страницу, затем проверяет и копирует `site/` в `dist/`; в публикацию попадают только файлы сайта.

## Где что менять

- `site/index.html` — содержание и семантическая структура.
- `site/styles.css` — токены, компоненты, системная тёмная тема и адаптивность.
- `site/motion.js` — общая пауза, видимость и условия воспроизведения фоновых видео и движения мяча.
- `site/gallery.js` — встроенные видеоплееры, просмотр фотографий, клавиатура и возврат фокуса.
- `content/zh-Hans.json` — перевод; `scripts/localize.mjs` генерирует `site/zh/index.html` из общей разметки. Сгенерированный HTML отдельно не редактируем.
- `site/weather.js` и `weather-model.js` — московское время, прогноз MET Norway и палитра.
- `site/assets/` — локальные фото, видео, SVG, шрифты и favicon.
- `site/404.html` — самостоятельная страница ошибки; абсолютная ссылка учитывает GitHub Pages `/vera/` и работает из вложенных URL.
- `AGENTS.md` — обязательные правила работы.
- `docs/PROJECT.md` — задача, решения и связь с базовым документом Notion.
- `docs/CONTENT.md` — подтверждённые сведения и неизвестные.
- `docs/BRIEF-FOR-VERA.md` — короткий бриф, который можно передать Вере.
- `docs/ASSETS.md` — происхождение и обработка опубликованных материалов.
- `docs/INSTAGRAM.md` — каталог 23 собранных теннисных материалов и границы просмотра.
- `docs/QA.md` — результаты проверки и ограничения.

## Публикация

Репозиторий: [anton-gorokhovatsky/vera](https://github.com/anton-gorokhovatsky/vera). Workflow `Quality` проверяет каждый push/PR. Workflow `Pages` проверяет, собирает и публикует `main`; GitHub Pages должен использовать GitHub Actions как источник. Адрес: `https://anton-gorokhovatsky.github.io/vera/`.

Черновая страница имеет `noindex, nofollow` до финализации контента. Это публичная ссылка для просмотра, не приватное хранилище. После согласования предложения следует снять `noindex` во всех страницах и обновить проверку, добавить окончательные canonical/OG-адреса и sitemap, перепроверить ссылки и публикацию. Не приписываем странице несуществующий домен, контакты или коммерческие условия.

Все 23 собранных материала доступны в галерее сайта. Визуальная основа — Further / Wimbledon: движущаяся трава, крупный набор, постерные карточки и кортовая геометрия. Актуальная система описана в `docs/DESIGN.md`, подробный разбор референса — в `docs/WIMBLEDON-REVIEW.md`.

Контент и контакт работают без JavaScript. Архив раскрывается через `details`, материалы открываются прямыми ссылками. Скрипты добавляют управление движением и просмотр внутри страницы. Удалённых шрифтов, встраиваний Instagram и сбора данных нет. Основные файлы ограничены 1,6 МБ; бюджет архива по запросу — 30 МБ.

Китайская версия: https://anton-gorokhovatsky.github.io/vera/zh/. Погода использует открытый прогноз MET Norway, кэшируется на час; без сети сохраняется палитра по московскому времени. Геолокация посетителя не запрашивается.
