# Вера Дуденкова · Большой теннис

Рабочая основа сайта тренера по большому теннису. На этой стадии подтверждены имя, профессия, Москва, профиль Instagram и запись через директ. Полное предложение собирается вместе с Верой.

## Запуск

Нужен Node.js 22 или новее. Установки пакетов нет.

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173/vera/`. Для другого порта: `PORT=4174 npm run dev`.

```sh
npm run check
npm run build
npm run preview
```

`check` проверяет базовые инварианты HTML, локальные ссылки/ресурсы, размеры и описания изображений, режим индексации и вес. Он не заменяет HTML-валидатор, аудит доступности и осмотр страницы в браузере. `build` копирует `site/` в `dist/`; в публикацию попадают только файлы сайта.

## Где что менять

- `site/index.html` — содержание и семантическая структура.
- `site/styles.css` — токены, компоненты, системная тёмная тема и адаптивность.
- `site/assets/` — локальные изображения и favicon.
- `site/404.html` — самостоятельная страница ошибки; абсолютная ссылка учитывает GitHub Pages `/vera/` и работает из вложенных URL.
- `AGENTS.md` — обязательные правила работы.
- `docs/PROJECT.md` — задача, решения и связь с базовым документом Notion.
- `docs/CONTENT.md` — подтверждённые сведения и неизвестные.
- `docs/BRIEF-FOR-VERA.md` — короткий бриф, который можно передать Вере.
- `docs/ASSETS.md` — происхождение фотографий.
- `docs/QA.md` — результаты проверки и ограничения.

## Публикация

Репозиторий: [anton-gorokhovatsky/vera](https://github.com/anton-gorokhovatsky/vera). Workflow `Quality` проверяет каждый push/PR. Workflow `Pages` проверяет, собирает и публикует `main`; GitHub Pages должен использовать GitHub Actions как источник. Адрес: `https://anton-gorokhovatsky.github.io/vera/`.

Черновая страница имеет `noindex, nofollow` до финализации контента. Это публичная ссылка для просмотра, не приватное хранилище. После согласования предложения следует снять `noindex` в обеих страницах и обновить проверку, добавить окончательные canonical/OG-адреса и sitemap, перепроверить ссылки и публикацию. Не приписываем странице несуществующий домен, контакты или коммерческие условия.

Сайт работает без JavaScript, удалённых шрифтов, встраиваний Instagram и сбора пользовательских данных. На мобильном и большом экране доступен один сценарий: познакомиться с Верой → узнать, как написать о тренировке → открыть её Instagram.
